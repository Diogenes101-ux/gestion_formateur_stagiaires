# Application de Gestion des Formateurs et Stagiaires

Une application web complète conçue pour faciliter le suivi, l'organisation et la gestion administrative des formateurs et des stagiaires au sein d'un établissement ou d'un centre.

## 🚀 Fonctionnalités
- Gestion des formateurs (Ajout, modification, affichage).
- Gestion des stagiaires.
- Simulation de base de données via des fichiers JSON.
- Architecture structurée (Modèles, Contrôleurs, Serveur).

## 🛠️ Technologies Utilisées
- **Frontend :** HTML5, CSS3, JavaScript
- **Backend :** Node.js, Express.js
- **Données :** JSON
